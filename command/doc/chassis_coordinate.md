# 车体坐标系与 CAN ID 映射

## 坐标系定义

```
                   车头 (+x)
                     ↑
                     │
   ┌─────────────────┼─────────────────┐
   │                 │                  │
   │    UNIT1        │   UNIT2         │
   │    0x121(转向)  │   0x123(转向)    │
   │    0x122(驱动)  │   0x124(驱动)    │
   │    前左          │   前右           │
   │   (x=+0.25)     │  (x=+0.25)      │
   │   (y=+0.30)     │  (y=-0.30)      │
   │                 │                  │
   ├─────────────────┼─────────────────┤
   │                 │                  │
   │    UNIT4        │   UNIT3         │
   │    0x127(转向)  │   0x125(转向)    │
   │    0x128(驱动)  │   0x126(驱动)    │
   │    后左          │   后右           │
   │   (x=-0.25)     │  (x=-0.25)      │
   │   (y=+0.30)     │  (y=-0.30)      │
   │                 │                  │
   └─────────────────┼─────────────────┘
                     │
                     ↓ 车尾 (-x)
```

## CAN ID 速查表

| 单元 | 位置 | 转向 CMD | 驱动 CMD | 转向状态帧 | 驱动状态帧 |
|------|------|----------|----------|-----------|-----------|
| UNIT1 | **前左** | **0x121** | **0x122** | 0x321 | 0x322 |
| UNIT2 | **前右** | **0x123** | **0x124** | 0x323 | 0x324 |
| UNIT3 | **后右** | **0x125** | **0x126** | 0x325 | 0x326 |
| UNIT4 | **后左** | **0x127** | **0x128** | 0x327 | 0x328 |

⚠ **重要：UNIT3=后右(0x125), UNIT4=后左(0x127)**，和编号直觉相反！

## 转向角约定

```
0°   → 正前 (+x 方向)
90°  → 正左 (+y 方向)
-90° → 正右 (-y 方向)
180° → 正后 (-x 方向)
```

**注意：** 本车的安装方式，公式输出的 90° 实际对应右移。
不需要取反，PID 直接执行公式输出的角度。

## 轮距参数

```
车体宽: 80cm × 80cm 正方形
轮间距: 60cm (左右)
轴距:   50cm (前后)

UNIT1 (0x121): 前左  x=+25cm, y=+30cm
UNIT2 (0x123): 前右  x=+25cm, y=-30cm
UNIT3 (0x125): 后右  x=-25cm, y=-30cm
UNIT4 (0x127): 后左  x=-25cm, y=+30cm
```

## 原地旋转

```
0 0 0.3 时各轮角度与受力 (omega>0 = 左旋):

前左 0x121: 220° → 向后右推  → 产生左旋扭矩  ✅
前右 0x123: 320° → 向前右推  → 产生左旋扭矩  ✅
后右 0x125:  40° → 向前左推  → 产生左旋扭矩  ✅
后左 0x127: 140° → 向后左推  → 产生左旋扭矩  ✅
```

omega>0 左旋，omega<0 右旋，对称。

## 运动学公式

```python
Vix = vx - omega * yi
Viy = vy + omega * xi
steer_deg = math.degrees(math.atan2(Viy, Vix))
drive_spd = math.hypot(Vix, Viy)
```

## 速度控制

```
# 调整输入值控制速度
vx/vy 取值范围: 0 ~ 0.8（对应 0% ~ 100% 动力）
omega 取值范围: 0 ~ 1.0

vx=0.2 → 25%  慢速
vx=0.4 → 50%  中速
vx=0.8 → 100% 最快

安全限制: MAX_MPS=0.8，禁止更高
```

### 仅转向不移动

```
steer 90    → 全部转 90°，驱动电机不动
steer 0     → 全部回正
steer 45    → 全部指向 45°（右前）
```
