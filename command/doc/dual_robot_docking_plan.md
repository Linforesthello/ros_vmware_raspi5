## 二、R2 底盘 CAN ID 映射

全向轮四个电机，每个独立控制正反转（无转向电机）：

| 轮位 | CAN ID | MCLM Group | 说明 |
|:----:|:------:|:----------:|------|
| FL 前左 | **0x123** | Group2 转向CMD | 用作独立驱动 |
| FR 前右 | **0x125** | Group1 转向CMD | |
| RL 后左 | **0x124** | Group2 动力CMD | |
| RR 后右 | **0x126** | Group1 动力CMD | |

MCLM_t2 固件以"电机对"形式工作（每板控制2个电机），
全向轮场景每板两个电机各驱动一个轮子。

## 三、全自动流程

```
┌──────────────────────────────────────────────────┐
│            上层协调器 (Coordination Script)       │
│   R1 和 R2 各运行在自己的 PC 上                   │
│   通过 TCP/共享文件/预置序列 同步                  │
└──────────────────────────────────────────────────┘
```

### 步骤序列

```
Step  R1 (舵轮+RS00)              R2 (全向轮+舵机臂)
─────────────────────────────────────────────────────────
 1    待机                         待机
 2                                底盘移动到物体位置(自动)
 3                                舵机臂放下→抓取物体(40pm端)
 4                                舵机臂抬起→摆到对接预备角度
 5   ~~~~~~~~~ R2 就绪信号 ~~~~~~~~~
 6    底盘移动到 PVC 杆位置(自动)
 7    RS00臂抓取 PVC 杆(30pm端)
 8    RS00臂调整姿态(PVC杆接近水平)
 9   ~~~~~~~~~ R1 就绪信号 ~~~~~~~~~
10    底盘慢速靠近 R2 (0.05 m/s)    舵机臂微调对准
11    RS00臂微调(30pm对准40pm)       保持姿态
12    快插到位检测
13   ~~~~~~~~~ 对接完成 ~~~~~~~~~
```

### 自动化的关键

**R2 全自动**意味着：
- R2 底盘接收 `vx vy omega` 指令 → 做全向轮逆运动学 → CAN 发给 4 个电机
- R2 臂接收 `角度指令` → CAN 0x130 发给 STM32 舵机控制器
- R2 按预设序列执行：定位→抓取→抬起→等待→微调

## 六、安全考虑

| 风险 | 程度 | 对策 |
|:----|:----:|:----|
| PVC 杆 1m 过长扫到人或设备 | 中 | 对接前确保工作区空旷 |
| RS00 大力矩伤人 | 高 | 限制最大力/速度 |
| 快插头卡住 | 低 | 设置力阈值，超限回退 |
| R2 全自动失控 | 中 | 硬件急停按钮 + 软件 watchdog |
