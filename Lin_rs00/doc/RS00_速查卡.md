# RS00 电机 CAN 指令速查卡 (Linux slcan)

> 基于 RS00 使用说明书 V1.1 (2026-04-10)
> 控制脚本: `rs00_control.py` + `rs00_arm.py`
> 被动监听: `monitor.py`

---

## 基本参数

| 项目 | 值 |
|------|-----|
| 电机默认 CAN ID | **127** (0x7F) |
| 主机 ID | **0xFD** (253) |
| 波特率 | **1 Mbps** (`-s8`) |
| 协议 | 私有协议（CAN 扩展帧 29-bit） |
| 供电 | 48 VDC（24-60V） |
| 减速比 | 10:1 |

---

## 帧结构通用规则

29-bit 扩展帧 ID:

```
bit28~24      bit23~8            bit7~0
┌──────────┐  ┌────────────────┐  ┌──────────┐
│ 通信类型   │  │  数据字段       │  │ 目标电机ID │
│ (5bit)    │  │  (16bit)       │  │ (8bit)   │
└──────────┘  └────────────────┘  └──────────┘
```

数值转换 (手册第55页):
```python
uint16 = int((x - x_min) * 65535 / (x_max - x_min))
```

物理范围常量:

| 量 | min | max | 对应角度制 |
|:--:|:---:|:---:|:---------:|
| 位置 | -12.57 rad | 12.57 rad | **±720°** |
| 速度 | -33 rad/s | 33 rad/s | **±1891 °/s** |
| Kp | 0 | 500 | — |
| Kd | 0 | 5 | — |
| 力矩 | -14 N.m | 14 N.m | — |

## 完整指令集映射表

### 下行指令 (主机 → 电机)

| 类型 | 名称 | CAN ID bit23~8 | 数据区 (8字节) | 应答 |
|:----:|:----:|:--------------:|:--------------:|:----:|
| **6** | **设机械零位** | 主机ID | `01 00 00 00 00 00 00 00` | Type 2 |
| **7** | **改CAN ID** | bit23~16=**新ID**, bit15~8=主机ID | `00 00 00 00 00 00 00 00` | Type 0 |
| **3** | **使能** | 主机ID | `00 00 00 00 00 00 00 00` | Type 2 |
| **4** | **停止** | 主机ID | `00 00 00 00 00 00 00 00` | Type 2 |
| **1** | **运控指令** | **前馈力矩 t_ff** | pos(2B)+vel(2B)+kp(2B)+kd(2B) | Type 2 |
| 17 | 读参数 | 主机ID | 索引LE(2B)+`00 00`+`00 00 00 00` | Type 17 |
| 18 | 写参数 | 主机ID | 索引LE(2B)+`00 00`+值(4B LE) | Type 2 |
| 22 | 保存到flash | 主机ID | `01 02 03 04 05 06 07 08` | Type 2 |

> LE = 小端序 (Little Endian)
> Type 6 的 Byte0 必须为 **0x01**（不是全零）

### Type 1 运控指令 — 数据区布局

| 字节 | 含义 | uint16范围 | 物理范围 |
|:----:|:----:|:----------:|:--------:|
| Byte0~1 | **目标位置** | 0~65535 | **±720°** |
| Byte2~3 | **目标速度** | 0~65535 | **±1891 °/s** |
| Byte4~5 | **Kp** | 0~65535 | 0~500 |
| Byte6~7 | **Kd** | 0~65535 | 0~5 |

控制公式: `t_ref = Kd×(v_set−v_act) + Kp×(p_set−p_act) + t_ff(CAN ID)`

### Type 2 应答帧 (电机 → 主机)

CAN ID 结构:

| 位域 | 含义 |
|:----:|:------|
| bit28~24 | **0x2** (类型) |
| bit23~22 | 模式状态: **0=复位, 1=标定, 2=运行** |
| bit21~16 | 故障位: bit16=欠压, 17=过流, 18=过温, 19=编码器, 20=堵转, 21=未标定 |
| bit15~8 | **回复的电机ID** |
| bit7~0 | 主机ID |

数据区 (8字节):

| 字节 | 含义 | 范围 |
|:----:|:------|:----:|
| Byte0~1 | **当前角度** | 0~65535 → ±720° |
| Byte2~3 | **当前速度** | 0~65535 → ±1891 °/s |
| Byte4~5 | **当前力矩** | 0~65535 → ±14 N.m |
| Byte6~7 | **温度** | **℃×10** (如 0x010E=27.0°C) |

## 常用指令 (电机ID=1, 主机ID=0xFD)

### 基础操作

| 操作 | 命令 |
|:----:|:------|
| **使能** | `cansend can0 0300FD01#` |
| **停止** | `cansend can0 0400FD01#` |
| **设机械零位** | `cansend can0 0600FD01#0100000000000000` |
| **读故障码** | `cansend can0 2200FD01#2230000000000000` |

### 阻尼模式

```bash
cansend can0 01800001#7FFF7FFF00003333
# pos=0 vel=0 kp=0 kd=1 → 拧轴有阻力
```

### 速度控制 (Kd=1)

| 速度 | 命令 |
|:----:|:------|
| **30 °/s** | `cansend can0 01800001#7FFF820100003333` |
| 60 °/s | `cansend can0 01800001#7FFF860300003333` |
| 90 °/s | `cansend can0 01800001#7FFF8A0500003333` |

### 位置控制 (Kp=10, Kd=1)

| 角度 | 命令 |
|:----:|:------|
| **0°** | `cansend can0 01800001#7FFF7FFF028F3333` |
| **30°** | `cansend can0 01800001#86067FFF028F3333` |
| **45°** | `cansend can0 01800001#8C097FFF028F3333` |
| **90°** | `cansend can0 01800001#8FFF7FFF028F3333` |
| **180°** | `cansend can0 01800001#9FFF7FFF028F3333` |
| **-45°** | `cansend can0 01800001#73F67FFF028F3333` |
| **-90°** | `cansend can0 01800001#6FFF7FFF028F3333` |

### 双电机 (ID=1 + ID=2)

```bash
cansend can0 0300FD01#   &&  cansend can0 0300FD02#           # 使能
cansend can0 01800001#8FFF7FFF028F3333                        # #1→90°
cansend can0 01800002#73F67FFF028F3333                        # #2→-45°
cansend can0 0400FD01#   &&  cansend can0 0400FD02#           # 停止
```

### 改 CAN ID

```bash
# 一次只接一个电机
cansend can0 0701FD7F#0000000000000000   # 127→1
cansend can0 0702FD7F#0000000000000000   # 127→2
```

### 参数读写

```bash
# 读故障码 (0x3022)
cansend can0 2200FD01#2230000000000000

# 写力矩限制 5 N.m (0x700B)
cansend can0 2400FD01#0B7000000000A040

# 保存参数
cansend can0 2C00FD01#0102030405060708
```

| 角度(°) | uint16 | 字节(高前低后) |
|:-------:|:------:|:--------------:|
| -720° | 0x0000 | 00 00 |
| -90° | 0x6FFF | 6F FF |
| -45° | 0x73F6 | 73 F6 |
| **0°** | **0x7FFF** | **7F FF** |
| 30° | 0x8606 | 86 06 |
| 45° | 0x8C09 | 8C 09 |
| **90°** | **0x8FFF** | **8F FF** |
| 180° | 0x9FFF | 9F FF |
| 270° | 0xAFFE | AF FE |
| 360° | 0xBFFE | BF FE |

### Kp/Kd/力矩

| 物理量 | 值 | uint16 |
|:------:|:--:|:------:|
| Kp | 0 | 0x0000 |
| Kp | 5 | 0x028F |
| **Kp** | **10 (默认)** | **0x051E** |
| Kp | 20 | 0x0A3D |
| Kd | 1 | 0x3333 |
| Kd | 2 | 0x6666 |
| 力矩 | 0 N.m | 0x8000 |

### Python 换算

```python
from rs00_control import float_to_uint, P_MIN, P_MAX, V_MIN, V_MAX

# 角度 → uint16
h = float_to_uint(90, P_MIN, P_MAX)   # 90° → 0x8FFF
print(f"{h>>8:02X}{h&0xFF:02X}")

# 速度 → uint16
h = float_to_uint(30, V_MIN, V_MAX)   # 30°/s → 0x8201
print(f"{h>>8:02X}{h&0xFF:02X}")
```

## Python API 快速调用合集

### 单电机模式（最快拷贝）

```python
from rs00_arm import RS00Arm
arm = RS00Arm(elbow_id=None)

arm.enable()
arm.set_zero()                                 # 当前位置→0°
arm.set_angles(45, 0, kp=150, kd=1).verify()   # 运控到 45°
arm.enable_csp(speed_limit=2)
arm.set_angles_csp(45, 0).verify()              # CSP 到 45°
arm.enable_operation()
arm.home().verify()                             # 归零
arm.disable()
```

### 双电机模式

```python
from rs00_arm import RS00Arm
arm = RS00Arm()                                 # 肩#1 肘#2

arm.enable()
arm.set_zero()
arm.set_angles(45, 20, kp=150, kd=1).verify()
arm.enable_csp(speed_limit=2)
arm.set_angles_csp(45, 20).verify()
arm.home().verify()
arm.disable()
```

### 运控模式常用（Type 1）

```python
# 双关节
arm.set_angles(肩膀°, 肘部°, kp=150, kd=1).verify()

# 单关节
arm.set_shoulder(角度°, kp=150, kd=1).verify()
arm.set_elbow(角度°, kp=50, kd=1).verify()

# 归零
arm.home(vel=30).verify()
```

### CSP 模式常用

```python
# 切 CSP + 设速限
arm.enable_csp(speed_limit=2)   # 2 rad/s ≈ 114°/s

# 设目标（限位+标零自动处理）
arm.set_angles_csp(肩膀°, 肘部°).verify()

# 动态调速（不重新切模式）
from rs00_control import write_param
import struct
write_param('can0', 0x7017, struct.pack('<f', 1.0), motor_id=1)
write_param('can0', 0x7017, struct.pack('<f', 1.0), motor_id=2)

# 切回运控
arm.enable_operation()
```

### 参数读写

```python
from rs00_control import write_param, read_param
import struct

# 读故障码
read_param('can0', 0x3022, motor_id=1)   # True=已发，看 monitor 回显

# 力矩限制 8 N.m
write_param('can0', 0x700B, struct.pack('<f', 8.0), motor_id=1)

# CSP 速度限制 1 rad/s
write_param('can0', 0x7017, struct.pack('<f', 1.0), motor_id=1)

# CAN 超时 500ms (0x7028: 20000=1s, 10000=500ms)
write_param('can0', 0x7028, struct.pack('<I', 10000), motor_id=1)
```

### 状态查询

```python
state = arm.get_state()
state['shoulder']['position']      # 角度°
state['shoulder']['velocity']      # 速度°/s
state['shoulder']['torque']        # 力矩 N.m
state['shoulder']['temperature']   # 温度°C
state['elbow']                     # 肘部（双电机时）
```

### 限位调整

```python
# 动态修改
arm.set_limits(shoulder_min=-85, shoulder_max=85)
arm.set_limits(elbow_min=-70, elbow_max=110)

# 查看当前限位
arm
# <RS00Arm ... 限位肩[-85°,85°] 肘[-70°,110°]>
```

### 链式一行流

```python
# 单电机：使能→标零→45°→验证→归零→停止
RS00Arm(elbow_id=None).enable().set_zero().set_angles(45,0,kp=150).verify().home().disable()

# 双电机：使能→标零→(45°,20°)→验证→归零→停止
RS00Arm().enable().set_zero().set_angles(45,20,kp=150).verify().home().disable()

# CSP 完整流程
RS00Arm().enable().set_zero().enable_csp(2).set_angles_csp(45,20).verify().enable_operation().home().disable()
```

### 上下文管理器

```python
# 单电机
with RS00Arm(elbow_id=None) as arm:
    arm.set_zero()
    arm.set_angles(45, 0, kp=150).verify()
    arm.enable_csp(2)
    arm.set_angles_csp(45, 0)
# 退出自动 disable

# 双电机
with RS00Arm() as arm:
    arm.set_zero()
    arm.set_angles(45, 20, kp=150).verify()
```

## CAN 接口启动

```bash
# 交互式
CanCmd
# 选 1) 1Mbps

# 手动
sudo slcand -o -c -s8 /dev/ttyACM0 can0
sudo ip link set can0 up
```
