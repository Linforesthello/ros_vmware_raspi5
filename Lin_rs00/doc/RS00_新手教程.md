# RS00 电机 从零到能转 — 完全新手教程

> 基于 RS00 使用说明书 V1.1 (2026-04-10)
> 指令映射与速查见 [RS00_速查卡.md](RS00_速查卡.md)

---

## 1. RS00 电机参数

| 参数 | 值 |
|------|-----|
| 额定电压 | **48 VDC**（24-60V） |
| 额定负载 | 5 N.m / 峰值 14 N.m |
| 空载转速 | 315 rpm（33 rad/s ≈ 1891 °/s） |
| **减速比** | **10:1** |
| 编码器 | 14bit 绝对值 |
| 通信 | CAN，默认 **1 Mbps** |
| 重量 | 310g |

---

## 2. 硬件接线

```
48V电源 ─── 电机电源 (XT30)
电脑 USB ─── CANable2 ─── CAN_H ─── 电机 CAN_H
                          CAN_L ─── 电机 CAN_L
```

终端电阻：CAN 总线两端需要 120Ω。多电机时并联在同一对 CAN_H/L 上。

---

## 3. 启动 CAN 接口

```bash
# 推荐: 交互式
CanCmd
# 选 1) 1Mbps → can0 UP

# 手动
sudo slcand -o -c -s8 /dev/ttyACM0 can0
sudo ip link set can0 up
```

设备路径可能是 `/dev/ttyACM0` 或 `/dev/ttyACM1`。

## 4. 私有协议核心规则

### 4.1 扩展帧 ID 结构

```
bit28~24: 通信类型 (5bit)
bit23~8 : 数据字段 (16bit) — 含义因类型而异
bit7~0  : 目标电机 CAN ID (8bit)
```

### 4.2 完整指令类型表

| 类型 | 名称 | 数据字段含义 | 数据区特征 |
|:----:|:----:|:------------:|:----------:|
| **6** | **设机械零位** | 主机ID | Byte0=**0x01**, 其余0 |
| **7** | **改CAN ID** | bit23~16=**新ID**, bit15~8=主机ID | 全0 |
| 3 | 使能 | 主机ID | 全0 |
| 4 | 停止 | 主机ID | 全0 |
| **1** | **运控指令** | **前馈力矩 t_ff** | 8字节控制参数 |
| 17 | 读参数 | 主机ID | 索引(2B)+保留+保留 |
| 18 | 写参数 | 主机ID | 索引(2B)+保留+值(4B) |
| 22 | 保存到flash | 主机ID | 固定 `01 02 03 04 05 06 07 08` |

### 4.3 Type 1 运控指令数据区

```
Byte0~1: 目标位置 [0~65535] → (±720°) / (±12.57 rad)
Byte2~3: 目标速度 [0~65535] → (±1891 °/s) / (±33 rad/s)
Byte4~5: Kp       [0~65535] → (0 ~ 500)
Byte6~7: Kd       [0~65535] → (0 ~ 5)
```

控制公式：
```
t_ref = Kd×(v_set - v_actual) + Kp×(p_set - p_actual) + t_ff(CAN ID)
```

### 4.4 Type 2 应答帧

电机收到指令后回复的反馈帧。CAN ID 结构：

| 位域 | 含义 |
|:----:|:------|
| bit28~24 | **0x2** |
| bit23~22 | 模式状态: 0=复位, 1=标定, **2=运行** |
| bit21~16 | 故障: 16=欠压, 17=过流, 18=过温, 19=编码器, 20=堵转, 21=未标定 |
| bit15~8 | **应答的电机ID** |
| bit7~0 | 主机ID |

数据区：

| 字节 | 含义 | 范围 |
|:----:|:------|:----:|
| Byte0~1 | **当前角度** | → **±720°** |
| Byte2~3 | **当前速度** | → **±1891 °/s** |
| Byte4~5 | **当前力矩** | → **±14 N.m** |
| Byte6~7 | **温度** | **℃×10** |

### 4.5 数值转换

```python
def float_to_uint(x, x_min, x_max, bits=16):
    span = x_max - x_min
    if x > x_max: x = x_max
    if x < x_min: x = x_min
    return int((x - x_min) * ((1<<bits) - 1) / span)
```

代码中已封装好角度制常量：
```python
P_MIN, P_MAX = -720.0, 720.0     # 位置范围 (°)
V_MIN, V_MAX = -1891.0, 1891.0   # 速度范围 (°/s)
```

### 4.6 角度换算表

协议角度 = **输出轴角度**（减速比 10:1 已在编码器端补偿）。

| 角度(°) | uint16 | 字节 |
|:-------:|:------:|:----:|
| **0°** | **0x7FFF** | 7F FF |
| 30° | 0x8606 | 86 06 |
| 45° | 0x8C09 | 8C 09 |
| **90°** | **0x8FFF** | 8F FF |
| 180° | 0x9FFF | 9F FF |
| 360° | 0xBFFE | BF FE |

## 5. 体验指令集 (电机ID=1, 主机ID=0xFD)

```bash
# 使能
cansend can0 0300FD01#

# 阻尼模式（拧轴有阻力）
cansend can0 01800001#7FFF7FFF00003333

# 慢速 30°/s
cansend can0 01800001#7FFF820100003333

# 转到 90°
cansend can0 01800001#8FFF7FFF028F3333

# 转到 180°
cansend can0 01800001#9FFF7FFF028F3333

# 回到 0°
cansend can0 01800001#7FFF7FFF028F3333

# 停止
cansend can0 0400FD01#
```

## 6. 改 CAN ID（Type 7）

两个电机出厂默认 ID=127，同一条总线上必须改成不同 ID。

**一次只接一个电机到总线。**

```bash
# 电机 #1: 127 → 1
cansend can0 0701FD7F#0000000000000000

# 断开 #1，接 #2
# 电机 #2: 127 → 2
cansend can0 0702FD7F#0000000000000000

# 都接上验证
cansend can0 0300FD01#   # 咔一声 → 成功
cansend can0 0300FD02#   # 咔一声 → 成功
```

脚本方式：
```bash
python3 -c "from rs00_control import set_can_id; set_can_id('can0', new_id=1)"
```

> 改 ID 立即生效。新版固件私有协议 ID 和 CANopen ID 一致。

---

## 7. 设机械零位（Type 6）

把臂摆到机械零点位置后执行：

```bash
cansend can0 0600FD01#0100000000000000
# Byte0=0x01 标记标零动作
```

> Type 6 的 Byte0 必须是 0x01，不是全零。之后电机认为当前位置为 0°。

脚本方式：
```python
# 在 rs00_control.py 中
set_zero_motor('can0', motor_id=1)
```

## 8. 双电机总线验证

两个电机并联在同一对 CAN_H/L 线上。

### 8.1 上电识别

电机上电时发 Type 0 广播帧，可识别各电机：

```
0x00007FFE  48 99 32 31 30 37 35 0D   ← 特征 48 99, 以 ID=127 广播
0x000001FE  48 99 32 31 30 37 35 0D   ← 同一电机以 ID=1 广播
0x00007FFE  2B 19 32 31 30 37 35 0D   ← 另一电机
0x000002FE  2B 19 32 31 30 37 35 0D   ← 同一电机以 ID=2 广播
```

数据前两字节为电机特征标识，同一电机在不同 ID 下的数据相同。

### 8.2 用脚本控制

```python
from rs00_arm import RS00Arm

with RS00Arm() as arm:
    # 标零
    arm.set_zero()
    # 同时控制
    arm.set_angles(90, -45, kp=10).verify()
    arm.home()
```

### 8.3 单独终端监听

```bash
# 终端1: 被动监听（不干扰控制）
python3 monitor.py

# 终端2: 任意发指令
cansend can0 01800001#8FFF7FFF028F3333
```

终端1自动捕获应答并显示：
```
肩膀#1:  89.8°  0.2°/s  0.001Nm  30.0°C  ●在线
```

## 9. 控制脚本功能总览

### rs00_control.py — 底层 CAN 指令

| 函数 | 类型 | 说明 |
|:------|:----:|:------|
| `motor_enable(iface, motor_id)` | Type 3 | 使能电机 |
| `motor_disable(iface, motor_id)` | Type 4 | 停止电机 |
| `motor_control(iface, motor_id, pos, vel, kp, kd, torque)` | Type 1 | 运控指令 |
| `set_zero_motor(iface, motor_id)` | Type 6 | 设机械零位 |
| `set_can_id(iface, new_id, current_id)` | Type 7 | 改CAN ID |
| `get_motor_state(iface, motor_id, kp_hold, kd_hold, ...)` | Type 1+监听 | 读状态（零干扰） |
| `write_param(iface, index, value_bytes, motor_id)` | Type 18 | 写参数 |
| `read_param(iface, index, motor_id)` | Type 17 | 读参数请求 |
| `set_mode(iface, motor_id, mode)` | Type 18 | 设运行模式 |
| `setup_can(device, baud, iface)` | — | 配置CAN接口 |
| `select_device()` | — | 自动检测设备 |

### rs00_arm.py — 双电机控制类

| 方法 | 说明 |
|:------|:------|
| `enable()` / `disable()` | 使能/停止（肘部 None 时跳过） |
| `set_angles(肩°, 肘°, kp=10, kd=1)` | 运控模式设角度（自动限位） |
| `set_shoulder(°)` / `set_elbow(°)` | 单关节控制 |
| `enable_csp(speed_limit, accel_limit)` | **切换 CSP 高刚度模式** |
| `set_angles_csp(肩°, 肘°)` | **CSP 模式设角度（含限位+标零）** |
| `enable_operation()` | 切回运控模式 |
| `set_zero()` | 标零（软件零点） |
| `set_limits(min, max, ...)` | 设置限位 |
| `get_state()` | 读双电机状态 |
| `verify(settle_time=2)` | 验证上次指令是否到位 |
| `home()` / `stop()` | 归零 / 急停 |
| `sleep(秒)` | 等待（链式支持） |

**Kp 推荐**：肩膀 **150**（扛自重），肘部 **50**。

**单电机模式**：
```python
arm = RS00Arm(elbow_id=None)     # 肘部跳过
arm.enable()                     # 只使能肩膀
arm.set_angles(90, 0, kp=150).verify()
```

链式调用：
```python
RS00Arm().enable().set_zero().set_angles(90,-45,kp=150).verify().sleep(2).home().disable()
RS00Arm(elbow_id=None).enable().set_zero().set_angles(90,0,kp=150).verify().disable()
```

上下文管理：
```python
with RS00Arm(elbow_id=None) as arm:
    arm.set_zero()
    arm.set_angles(45, 0, kp=150).verify()
    arm.enable_csp()
    arm.set_angles_csp(45, 0)
```

CSP 完整用法：
```python
arm.enable_csp(speed_limit=2)          # 2 rad/s ≈ 114°/s
arm.set_angles_csp(90, -45).verify()   # 限位+标零自动处理
# 动态调速
from rs00_control import write_param
import struct
write_param('can0', 0x7017, struct.pack('<f', 1.0), motor_id=1)
arm.enable_operation()                 # 切回运控
```

### monitor.py — 纯被动监听

```bash
python3 monitor.py              # 两个电机
python3 monitor.py --id 1       # 只肩膀
python3 monitor.py --id 2       # 只肘部
```

**纯被动监听，绝不发送任何指令**，可在其他终端同时用 Python REPL 或 cansend 控制，互不干扰。

## 10. Type 18 写参数详解

帧结构：
```
扩展帧 ID = 0x12<<24 | 主机<<8 | 电机ID
Byte0~1: 参数索引（小端序）
Byte2~3: 0x00 0x00
Byte4~7: 参数值（小端序, float 或 uint）
```

**Type 18 掉电丢失**，需 Type 22 保存。

### 示例：改力矩限制

```python
from rs00_control import write_param
import struct

# 力矩限制 5.0 N.m → float 小端字节
write_param('can0', 0x700B, struct.pack('<f', 5.0), motor_id=1)

# 保存到flash
# cansend can0 2C00FD01#0102030405060708
```

### 常用参数索引

| 索引 | 名称 | 类型 | 说明 |
|:----:|:----:|:----:|:------|
| 0x7005 | run_mode | uint8 | 0=运控 2=速度 5=CSP |
| 0x7006 | iq_ref | float | 电流模式指令 (-16~16A) |
| 0x700A | spd_ref | float | 速度指令 (-33~33 rad/s) |
| **0x700B** | **limit_torque** | float | **力矩限制 (0~14 N.m)** |
| 0x7016 | loc_ref | float | CSP位置指令 (rad) |
| **0x7017** | **limit_spd** | float | **CSP速度限制 (0~33)** |
| **0x7018** | **limit_cur** | float | **电流限制 (0~16A)** |
| 0x701E | loc_kp | float | 位置环Kp (默认40) |
| 0x701F | spd_kp | float | 速度环Kp (默认6) |
| 0x7020 | spd_ki | float | 速度环Ki (默认0.02) |
| 0x7022 | acc_rad | float | 速度加速度 (默认20) |
| **0x7028** | **canTimeout** | uint32 | **CAN超时 (20000=1s)** |
| 0x7029 | zero_sta | uint8 | 零点范围 |
| **0x702B** | **add_offset** | float | **零位偏置 (-7~+7)** |

## 11. 故障码

| 位 | 含义 |
|:--:|:------|
| bit0 | 电机过温 >145℃ |
| bit1 | 驱动芯片故障 |
| bit2 | 欠压 <12V |
| bit3 | 过压 >60V |
| bit7 | 编码器未标定 |
| bit14 | 堵转过载 |

读取：
```bash
cansend can0 2200FD01#2230000000000000
# 应答帧 Byte4~7 为故障码值
```

## 12. 常见问题 FAQ

| 现象 | 原因 | 解决 |
|:------|:------|:------|
| `cansend: error 105` | 接口没 UP | `sudo ip link set can0 up` |
| `cansend: error 19` | 设备不存在 | `ls /dev/ttyACM*` 确认路径 |
| 发指令无反应 | 波特率不匹配 | 必须 `-s8` (1Mbps) |
| 使能后"咔"锁住但不转 | 正常！通信成功 | 检查 Type 1 参数 |
| 两个电机只一个响应 | CAN ID 冲突 | 确认 ID 不同 |
| 上电只有 0x00007FFE | 某电机 ID 还是 127 | 用 Type 7 改 ID |
| **monitor 与控制冲突** | monitor 发了查询指令 | **已修复**为纯监听 |
| **监控数据消失** | 超时清空 | **已修复**为保留最后值 |
