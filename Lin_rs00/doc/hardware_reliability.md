## 一、STM32F103C8T6 瓶颈分析

| 问题 | 说明 | 缓解对策 |
|:-----|:------|:----------|
| **无FPU** | 浮点PID运算靠软件模拟，1kHz控制环吃30-50% CPU | 使用定点PID(Q15/Q31)，或降频至500Hz |
| **RAM仅20KB** | FreeRTOS+任务栈+HAL+SPI缓冲+CAN队列 | 确认编译后实际占用，必要时裸机状态机 |
| **Flash仅64KB** | HAL+FreeRTOS+CAN+SPI+PID占用~38-42KB | 去掉printf浮点支持可省~12KB |
| **单CAN外设** | 仅1路CAN，不能同时接两条物理CAN总线 | 同一总线逻辑分路 |

### SteeringArm_t1 的 FreeRTOS 堆栈分析

```
configTOTAL_HEAP_SIZE = 3072   # 仅 3KB 堆

任务栈:
  CAN_Rx_Ta      1024 字节
  DC_Motor_Ta    1024 字节
  Arm_State_Ta   1024 字节
  Heartbeat_Ta    256 字节
  Servo_Ta        256 字节
  合计栈         ~3.5KB
  F103C8T6总RAM   20KB
```

建议编译后检查实际RAM占用。如果接近上限，考虑移除FreeRTOS改用裸机状态机。

### 推荐 MCU 升级路径

| MCU | FPU | RAM | CAN | 成本增量 | 建议时机 |
|:----|:---:|:---:|:---:|:--------:|:---------|
| F103C8T6 (当前) | ❌ | 20KB | 1 | 基准 | 当前够用 |
| F103RC | ❌ | 48KB | 1 | ~¥3 | RAM不够时换 |
| **F303** | ✅ | 40KB | 2 | ~¥8 | 需要双路物理CAN时 |
| **G431** | ✅ | 32KB | 2 | ~¥7 | 需要更高性能+双CAN |

## 二、1m 长杆操作风险

### 杆参数

- 材质: PVC
- 重量: 200-300g
- 长度: 1m
- 质心距夹爪: ~0.5m（夹持一端时）

### 各关节负载

| 关节 | 水平最大受力 | 额定/余量 |
|:-----|:------------|:----------|
| 关2(肘) RS00 | 1.225 Nm | 额5Nm / 余量 >3x |
| 关3(腕) DC电机 | ~0.25 Nm | 取决于减速比 |
| 夹爪舵机 | 2.94N重力 | 35kg.cm ≈ 137N夹持力 |

### 安全操作规则

1. **必须实现轨迹插补** — 不能阶跃跳角度
2. **必须启用力矩限制** — RS00有 `limit_torque` 参数（Type 18写0x700B）
3. **急停不应直接 disable** — 重力会砸下。应先切高阻尼位置保持，确认静态后再断电
4. **硬件急停按钮** — 必须串入48V电源回路

### 急停时序（建议）

```
急停触发
  → 立即: 阻尼保持 (RS00改高Kd, DC电机刹车)
  → 500ms: 确认静止 (读转速≈0)
  → 1s:    disable/断电
```

## 三、关节3（腕旋转）关键设计

### 架构

```
DC电机 (自带霍尔编码器)        从动轮 (MT6701)
  ┌───┐                    ┌────────┐
  │ M │──────齿轮减速──────→│ 输出轴  │──→ 夹爪
  └───┘                    └────────┘
    ↑                         ↑
  TIM2编码器(速度内环)       SPI读MT6701(位置外环)
  10ms                       50ms
```

### 串级位置环

```
位置环 (外环, 50ms)        速度环 (内环, 10ms)
MT6701 绝对值反馈           TIM2 霍尔编码器
  ↓                          ↓
位置误差 → P控制 → 速度目标 → PID → PWM → DC电机
                    ↑                ↑
                齿隙死区补偿       TB6612 H桥
```

### 存在的风险

| 风险 | 影响 | 对策 |
|:-----|:------|:------|
| DC电机断电不自锁 | 杆重力导致腕部旋转 | 蜗轮蜗杆减速器 / 断电前回安全姿态 |
| 齿隙(Backlash) | 位置精度下降 | 2°死区补偿(plan_steering_arm.md有设计) |
| MT6701回差 | 角度读数滞后 | 外环周期50ms足够，影响小 |

## 四、通信可靠性

| 环节 | 风险 | 硬件缓解 | 软件缓解 |
|:-----|:------|:----------|:----------|
| CAN总线 | 物理断线全系统失联 | 差分对抗干扰 | 各节点独立急停逻辑 |
| USB-CANable2 | USB断连 | 固定线缆 | 检测断连后安全姿态 |
| ROS2节点crash | 无指令下发 | — | STM32超时自主停车 |
| 网关死机 | 失去融合帧 | — | N100降级到原始数据 |
| CAN终端电阻 | 反射误码 | 两端120Ω | — |

### 各节点超时安全行为

| 节点 | 超时检测 | 安全动作 |
|:-----|:---------|:---------|
| MCLM | 50ms状态帧内嵌 | 清空setpoint, 滑行停止 |
| SteeringArm | CAN帧超时 | 舵机保持最后位置(g_servo_active) |
| RS00 | 可由Type 18设参数 | 保持最后指令位置 |
| N100 CAN#2 | 网关融合帧超时(>500ms) | 降级到CAN#1原始数据 |

## 五、夹爪同步方案

两个 35kg.cm 数字舵机并列夹持 1m 杆：

- **推荐**: 两个舵机用同一路PWM信号（信号线并联），机械刚性固定
- 天然同步，不需要额外控制逻辑
- 舵机由 STM32#2 的 TIM4_CH3/CH4 输出 PWM（50Hz）
- PWM 范围: 500μs~2500μs 对应 0°~300° 全行程
- 供电: 5V 独立轨（与 STM32 的 3.3V 不共轨）
