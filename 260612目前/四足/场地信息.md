## 四、机器人规格要求

### 4.1 机器人类型

- 全足式机器人（单足/双足/多足均可）：
  - 每条腿自由度数 ≥ 2
  - 与地面接触的是机器人足部
- 轮腿式机器人：
  - 每条腿自由度数 ≥ 3（2 个腿关节 + 1 个驱动轮）
  - 与地面接触的是带驱动的轮子

### 4.2 尺寸与重量限制

| 参数 | 限值 |
|------|------|
| 自然站立外形尺寸 | ≤ 800mm × 600mm × 600mm |
| 足部接地的外接圆直径 | ≤ 80mm |
| 轮子厚度 | ≤ 60mm |
| 本体总重（含机载电池+遥控盒） | ≤ 35kg |

### 4.3 能源限制

| 项目 | 要求 |
|------|------|
| 能源类型 | 电池 和/或 压缩空气 和/或 弹性力 |
| 电池标称电压 | ≤ 48V |
| 压缩空气气压 | ≤ 600kPa |

### 4.4 参赛队

| 项目 | 要求 |
|------|------|
| 每校最多参赛队数 | 2 个 |
| 每队学生成员 | ≤ 10 人（同校） |
| 上场队员 | ≤ 3 人 |

## 五、障碍赛规则要点

### 5.1 越障成功定义

| 障碍 | 成功条件 |
|------|----------|
| **直角绕杆** | S 型绕过每根竖杆，从一侧必达区到另一侧必达区，中间经过拐角必达区 |
| **砂砾碎木坑** | 从 1m 短边进出，≥ 1/2 足触地面（含 1/2）则失败重来 |
| **高墙** | 从上方跃过或攀爬通过 |
| **限高杆** | 以任意姿态从下方穿过，碰掉横杆则失败 |
| **T 字形台阶** | 每一级台阶顶面至少一次足底接触，≥ 1/2 足触地面则重来 |
| **大斜坡** | 在两侧斜坡上沿 3m 长边方向各行走 ≥ 1m，≥ 1/2 足触地面则重来 |
| **木桥 A/B** | 从一侧平台通过木桥行至另一侧平台，≥ 1/2 足触地面则重来 |

### 5.2 障碍赛得分

| 障碍名称 | 自动控制 | 遥控控制 | 备注 |
|----------|----------|----------|------|
| 直角绕杆 | 150 | 100 | — |
| 砂砾碎木坑 | 150 | 100 | 完整通过才计分 |
| 高墙 | 150 | 100 | — |
| 限高杆 | 150 | 100 | — |
| T 字形台阶 | 150 | 100 | 上台阶/下台阶各 75/50 分，可拆分 |
| **大斜坡** | **150** | **100** | **两侧斜坡不分开计分** |
| 木桥 A | 150 | 100 | 通过小斜坡上下平台不计分 |
| 木桥 B | 150 | 100 | 通过小斜坡上下平台不计分 |
| **返回启动区（额外加分）** | **+100** | **+100** | 完成全部越障后返回所选启动区 |

### 5.3 障碍赛犯规罚分

每出现一次以下情况，罚 20 分：

- 未经允许接触机器人
- 操作手未按规定站位
- 有意损坏场地设施
- 其他违反规则的行为

## 六、任务赛规则要点

### 6.1 任务说明

- 从 8 个随机分布的物资箱中识别 4 类物资箱
- 移送到对应的归位区
- 不得以踢、踹、撞等粗暴方式移送

### 6.2 任务赛得分

| 条件 | 得分 |
|------|------|
| 物资箱完全在对应归位区内（不出界） | 100 分 |
| 物资箱压线出界 | 60 分 |
| 每归位区最多放置 | 2 个物资箱 |
| 叠放时上方物资箱 | 100 分 |
| 叠放时下方物资箱 | 按是否压线判定 |
| 高分区物资箱 | 得分 ×2（由智力题目答案对 4 取模确定高分区编号 0-3） |

### 6.3 任务赛罚分

每出现一次以下情况，罚 20 分：

- 未经允许进入场地
- 未经允许接触机器人
- 错放物资箱至不对应归位区（含压线）
- 暴力方式移送物资箱
- 有意损坏场地设施
